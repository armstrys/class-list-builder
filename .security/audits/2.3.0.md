## Changes Since v2.2.3

This release introduces a major new feature — the **Class Balance Assessment**
system — and removes the StatsStrip component:

1. **Assessment Engine** (`src/utils/assessment.js`) — New module that computes:
   - Per-class aggregate statistics (means for numeric criteria, rates for flags)
   - Unconstrained optimal baseline via multi-restart simulated annealing
   - Random assignment baseline via 1,000 batched random trials
   - Normalized 0–100 Balance Score using power-law transform
   - Async computation with progress callbacks to avoid blocking UI

2. **Assessment Modal** (`src/components/AssessmentModal.js`) — New UI component
   displaying the Balance Score, baseline comparison table, and per-class
   statistics with color-coded indicators.

3. **Toolbar Integration** (`src/components/OptimizePage.js`) — Balance Score
   badge added to toolbar (clickable, opens AssessmentModal). Assessment
   auto-runs asynchronously when assignments change. Removed StatsStrip component
   and associated code.

4. **Print Report** (`src/components/PrintReportView.js`) — Added Balance
   Assessment section to the print report cover page with score and cost table.

5. **State Management** (`src/contexts/index.js`) — Added `assessment`,
   `setAssessment`, `isAssessing`, `setIsAssessing` to StudentsContext.

6. **Optimizer Enhancement** (`src/optimizer.js`) — Added optional `seedSalt`
   parameter to `computeSeed()` and `optimize()`, enabling independent SA
   trajectories for multi-restart baseline computation.

7. **Sample Data** (`src/sample-data.js`) — Doubled sample constraint counts
   (8–12 keepApart, 4–6 keepTogether, 4–6 keepOutOfClass). Added
   `generateSampleConstraints()` for demo data.

8. **Tests** — Added `tests/assessment.test.js` (599 lines) with deterministic
   baseline tests. Updated `tests/optimizer.test.js` and
   `tests/display-normalization.test.js`.

9. **Documentation** (`README.md`) — Updated Balance Score documentation with
   new 0–100 scale, scoring explanation, and assessment dialog description.
   Removed StatsStrip documentation.

10. **Build** (`class-list-builder-source.html`) — Added `assessment.js` and
    `AssessmentModal.js` to script loading order.

## Vulnerability Findings

No findings.

The `Math.random()` usage in `computeBaselineRandom()` and
`computeBaselineRandomAsync()` (via `assessment.js:132-133`, `assessment.js:172-173`)
is informational only — random baseline generation for the assessment score
does not require cryptographic randomness or determinism. The optimizer itself
continues to use its seeded RNG for reproducible results.
